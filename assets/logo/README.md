# Логотип GigaMail

| Файл | Где использовать |
|---|---|
| `gigamail-mark.svg` | знак отдельно: иконки, аватары, вкладка браузера |
| `gigamail-favicon-16.svg` | знак для размера 16 px и меньше: без клапана и с толстой линией, чтобы не слипался |
| `gigamail-logo-light.svg` | знак и название на светлом фоне |
| `gigamail-logo-dark.svg` | знак и название на тёмном фоне |

Цвета: зелёный `#21a038`, белый `#ffffff`. Название набрано шрифтом из системы (Roboto, Segoe UI, Arial),
поэтому для печати и презентаций лучше перевести текст в кривые в редакторе.

Знак встроен в `mailbot/static/index.html` прямо в разметку: веб-интерфейс не раздаёт отдельные файлы.
