Категории и промпты

Модель читает этот промпт при разборе каждого письма, вместе с промптами остальных категорий. На этом шаге она не запускает инструменты и не открывает файлы, поэтому здесь описывайте признаки письма.
Этот промпт уходит агенту по кнопке в письме: скиллы, пути к файлам, код и команды пишите здесь. Если он пуст, кнопки действия не будет.
Параметры действуют при запуске по кнопке. Пустое поле — значение из настроек или сервиса GigaCode.
Список попадает в промпт запуска: на место {files}, а если этой переменной нет — в конец.
Каталоги должны существовать на машине, где работает сервис GigaCode. Иначе запуск завершится ошибкой.
Проверка использует текущий текст, даже несохранённый. Письмо при этом не меняется.

По одному адресу или домену на строку. Если белый список заполнен, берутся только письма из него; если пуст — все. Чёрный список важнее белого. Отсеянные письма не сохраняются и не уходят в модель. Списки действуют на новые письма.

Сущности

      
Значения, которые модель достаёт из письма, как Jira-ключ. Каждая сущность становится переменной {код} в промптах. Значения появляются у новых писем, для старых нажмите «Переразобрать письма» на странице категорий.
